# iFace v1.5.0 发布说明

> 状态：草稿。外部服务 smoke 和人工验收补齐后改为正式版本。

## iFace v1.5.0

1.5.0 是一次界面和代码结构的整体重构：换上更克制的极简界面，所有页面用新的组件库重建，状态层和数据访问也一并整理。刷题、笔记、AI、备份和同步的数据格式保持兼容，升级后不需要迁移。

### 界面

- 全新外观：桌面端侧边栏外壳，移动端顶栏和抽屉菜单；统一的设计 token，亮色 / 暗色主题一致。
- 新 logo：黄色圆角方块里一个眨眼的笑脸，替换原来的墨镜表情；网站图标、PWA 图标（含 maskable）和侧边栏同步更新。
- 主题新增「跟随系统」（新用户默认），随操作系统的浅色 / 深色自动切换；侧边栏主题按钮改为浅色 / 深色 / 跟随系统菜单，设置「偏好」和命令面板也可以切换。
- 颜色更好认：每个模块有自己的颜色和图标（题库侧栏、列表、练习、概览、薄弱点、题目页），难度用绿 / 橙 / 红区分；主按钮和选中态使用靛蓝主色。
- 新增 `⌘K` / `Ctrl K` 命令面板，可以搜索题目、跳转页面、打开设置。
- 概览页：继续上次、今日目标、统计、今日推荐、活跃度热力图、模块进度、最近笔记。
- 题库页：分类侧栏、搜索（包含笔记内容）、筛选与排序；筛选状态写在 URL 里，可以分享和回退。
- 左侧导航可以拖动调整宽度，拖到最窄或按 `[` 折叠成图标栏（悬停显示名称），宽度和折叠状态会记住。
- 题目详情页：新的题目区和答案卡片；长答案右侧显示目录栏（空间足够时），点击跳转并随滚动高亮。
- 「掌握得怎么样？」不再悬浮遮挡答案：读完答案后在卡片末尾评分（显示下次复习时间），读到一半可以用顶栏的红 / 橙 / 绿三个按钮或 `1` / `2` / `3`；手机底栏先放「查看答案」，展开后换成三个评分按钮。
- 笔记和 AI 助手合并为题目详情右侧的**停靠侧栏**（`N` / `A` 切换，`Esc` 关闭）：桌面端与答案并排、不再遮挡内容，宽度可拖动，翻题时保持打开；手机上是底部面板。
- 本模块题目列表（题目页左上角模块名或 `L`）在宽屏上停靠在页面左侧：可搜索、按状态筛选、方向键切换，宽度可拖动，翻题时保持打开；空间不够或手机上是左侧抽屉。两侧栏同时打开时会自动分配宽度，保证正文可读。
- 笔记改为编辑优先：空笔记打开即可输入，已有笔记先显示渲染结果、点击正文进入编辑，`⌘↵` 预览。
- AI 对话重新排版：回答以全宽正文显示，快捷指令收进输入框工具栏，清空对话可以撤销。
- 更轻快：切换题目不再有淡入 / 缩放动画和加载闪烁（题库已在内存时同步渲染），答案卡片、AI 消息、目录栏等页面内容去掉入场动画，停靠侧栏直接出现；加载占位只在超过约 250ms 时才显示；对话框、抽屉、菜单的动画缩短到 100–200ms。
- 学习检验、Markdown 渲染全部改用新组件和 token 样式。
- 设置从 3.6k 行的抽屉改为按 tab 拆分的对话框（偏好 / AI / 数据 / 同步 / 关于）。新增「关于」页：版本号、源代码 / 更新日志 / 反馈链接、全部快捷键、数据与隐私说明，以及「重新查看新手引导」。
- 表单自动保存草稿：简历 JD 诊断、AI 工具箱各工具（含上次结果）、模拟面试设置和未发送的回答、粘贴导入、出题选项、练习组合都会记住，离开页面或刷新后还在；正在进行的模拟面试返回后自动打开。「新诊断」清空材料可以撤销；AI 设置未保存的修改切换 tab 或关闭设置后保留。
- 题库列表：从题目返回会回到原来的滚动位置和已加载的条目；滚动到底自动加载更多；搜索和筛选栏吸顶。
- 手机端练习页底部固定显示「开始练习」；快速开始和模块选择改为两列，少滑一大半。题库列表在手机上标题最多显示两行，不再一行截断。
- 答案更好读：正文 16px、标题层级更清楚；行内代码改为中性色，不再和链接抢眼；代码块关闭连字，`===`、`!==` 按原样显示。
- 手机阅读：答案去掉卡片边框，正文和代码块用满屏宽；底部切题栏默认开启（设置里可关），开启时顶部和页尾的上一题 / 下一题不再重复出现；页面标题栏随内容滚走，只保留顶栏；作答框不再自动聚焦弹出键盘。
- 答案卡片工具栏去掉「讲解题目」「讲解知识点」两个一点就直接发送的按钮，保留编辑答案和 AI 助手入口；同类的分析考点 / 答题结构 / 讲解知识点在 AI 面板里一键可选。
- 薄弱点、模拟面试（聊天式面试间 + 评分报告）、导入、出题、AI 工具箱、简历 / JD 诊断、首次引导全部重建。首次引导介绍 1.5 的主要用法（`Space` 看答案、`1` / `2` / `3` 评分、`N` / `A` 侧栏、命令面板），最后一步可以直接选择主题，之后随时可以在「设置 → 关于」重新打开。

### 学习功能

- 练习页新增快速开始：到期复习、待复习、学新题、随机。
- 间隔复习：根据现有学习记录推算到期时间（待复习次日、已掌握 7 / 14 / 30 / 60 天），不改存储格式。
- 薄弱点页显示到期状态，标记掌握后可以撤销。
- 导入页支持直接粘贴 Markdown 题目，并显示各来源题目数量。

### 修复

- 笔记在自动保存的 650ms 等待期内切题、关闭侧栏或刷新页面，最后输入的内容会丢失；现在会立即保存，页面关闭时先暂存到本地、下次打开自动恢复。
- 手机端练习页（以及概览页在某些内容下）出现横向滚动条，已修复。
- 打开对话框时页面会向左抖动几个像素（滚动锁定额外加了右边距），已修复；滚动条改用标准 `scrollbar-color` / `scrollbar-width`，并固定预留滚动条位置。
- 内置题库迁移不再误删自定义题目：以前 Markdown 导入自动生成的 id（例如 `js-001`）可能和内置题 id 撞上，迁移时被当成重复题删除。现在除了 id 还要求模块和题干 / 答案一致。
- 备份导入、Gist 拉取后，内存中的学习记录会自动刷新，不再显示旧数据。
- PWA 同源运行时缓存路由此前用 RegExp 匹配完整 URL，永远匹配不上，已改为按 pathname 匹配。

### 性能

- 题库和学习检验 JSON 不再预缓存，改为 `NetworkFirst` 运行时缓存，预缓存从约 6.5 MB（104 项）降到约 1.6 MB（76 项）。
- 设置对话框、Gist 同步按需加载，React 单独分包；入口 chunk 从约 613 kB 降到约 325 kB，构建不再有大 chunk 警告。

### 工程

- 状态层改用 zustand 单例 store（`useStudyState`、`useAIState` 等），localStorage 读写集中到 `src/lib/storage.ts`。
- 新增可替换的 data source 接口，为后续 QFace 后端预留。
- 页面按 `src/features/<feature>/` 组织，纯逻辑放在同目录 `*.ts` 并配单元测试。
- 新增 Vitest 单元测试和 Playwright E2E smoke 测试，`check:all` 增加 `bun run test`。
- 开发模式下 `/design` 展示所有组件和 token。

### 数据与兼容性

- IndexedDB：结构和版本号不变。
- localStorage：已有键名和格式不变；`iface_theme` 新增取值 `system`（跟随系统，未设置时的默认值），原有的 `light` / `dark` 照常生效；不再使用 `iface_streak_banner_dismissed_date`（概览页旧横幅已移除，遗留值无影响）。`iface_mobile_question_nav_enabled`（手机底部切题栏）未设置时默认改为开启，手动设置过的保持原样。新增仅本机生效的界面偏好 `iface_sidebar_width`、`iface_sidebar_collapsed`、`iface_side_panel_width`、`iface_module_panel_pinned`、`iface_module_panel_width`，页面关闭时暂存未保存笔记的 `iface_note_draft`（下次打开写回 IndexedDB 后删除），以及表单草稿 `iface_draft:<表单>`（例如 `iface_draft:jd-match`，内容恢复默认或提交后删除）；这些键不参与备份和同步。
- 内置题库 JSON：内容不变（1222 道题，29 个文件）。
- 备份文件、Gist 同步格式：不变，旧备份可以直接导入。

### 外观变化说明

Markdown 样式迁移到 token 类名后有几处有意的细微变化：答案第一个标题和最后一段不再有外边距；未标注语言的代码块和普通代码块样式一致；表格改为外框 + 行分隔线。

### 升级前确认

```bash
bun run check:all
```

`check:all` 包含 `bun run check`、`bun run test`、`bun run check:version`、`bun run check:release`、`bun run check:quality-gate`、`bun run check:docs`、`bun run check:external-records`、`bun run check:backup`、`bun run check:questions`、`bun run check:sync`、`bun run check:ai`、`bun run build`、`bun run check:pwa`。其中 `check:external-records` 需要先用真实凭证运行 `bun run smoke:external:ai` 和 `bun run smoke:external:gist`。
